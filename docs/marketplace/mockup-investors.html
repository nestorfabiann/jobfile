What changes
  • Project type when posting: My home, Flip or Rental. Homeowners are not affected.
  • Property nickname (address stays private as today) so an investor can run several jobs.
  • Repeat a past job: copy the scope to a new property in one tap.
  • Investor extras: quick turnaround and pay per milestone flags that contractors see.
  • Portfolio page under Projects: all properties, open bids, spend, done jobs.
  • Contractor side: an "Investor" tag, a repeat-client note ("posted 3 jobs, paid on time"), and an Investor filter in Find work.
  • Not included: raising money or sharing profit with other investors. That could be a securities issue and needs a lawyer first.
  • Needs a small database step. Mockup only, not built.

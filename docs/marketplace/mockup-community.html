How it stays safe

  • Showcase posts come only from finished Jobfile projects. That is the trust badge, and no one can fake it.
  • The homeowner approves every post about their home, then Jobfile reviews it before it appears.
  • No addresses, last names, phone numbers, emails or links. The same filter we use on bids, applied to captions and comments.
  • Report and hide: any post or comment can be reported. Admin can remove it and suspend repeat offenders.

Why it helps

  • Homeowners get ideas and confidence before they post a project.
  • Contractors get free, credible marketing from work they already did, with the badge to prove it.
  • It feeds the marketplace. "Start a project like this" and "Get bids" bring new posts.

Suggested order

  • First: the feed, project pages, likes, saves, and "Start a project like this".
  • Then: share from a finished project, with homeowner approval and admin review.
  • Later: comments and "Ask for ideas" polls, since these need the most moderation.

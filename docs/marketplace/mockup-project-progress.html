What changes
  • Numbered circles joined by a line. Done steps get a check, the current step is bigger and pulses softly, later steps are quiet.
  • A "where you are" block under it. The current phase from the Schedule tab, the day count, and a thin progress bar.
  • Money in one line. Paid so far of the agreed price, and what is next. Contractors see money received and the next payment request.
  • One clear next action. Green when nothing is needed. Orange with a button when it is (pay, approve, request).
  • Tappable steps. Agreement opens the agreement, Closeout opens the closeout page.
  • Real data only. Phase and day count come from the schedule. If there is no schedule, that line is simply left out.
  • Calm. One soft pulse, switched off for people who set reduced motion. No percentage rings or confetti.

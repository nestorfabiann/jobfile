About Settings
How do I change how I’m alerted?⌄
Choose Email and Text, and turn on phone alerts. Texts never include message content.
Why is my ZIP code here?⌄
It shows contractors near you. Your street address is never shared.
Can I read messages in Spanish?⌄
Yes. Pick your language, and new messages can be translated automatically. Translations are made by AI.

How it works
  • "On this page" chip. New first chip. It is selected when the page has its own questions, and it shows only those. "All" and the other chips work as before.
  • Every Menu page gets its own set. Home, Projects, Marketplace, Community, Find contractors, Collaborate (already done), Settings, Business profile, Invite friends and Get the app. Homeowners and contractors each see the questions that apply to them.
  • A page with no questions opens on All, as it does today. No empty chip.
  • Search still searches everything, so a typed question finds its answer from any page.
  • Plain answers. Short, and true to how the app works today. When a feature changes, the answer changes with it.
  • No AI. These are written answers, so they are always the same and never invented.

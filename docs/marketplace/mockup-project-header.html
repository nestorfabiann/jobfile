What changes
  • About half the height. The big orange block becomes a compact card, so progress and next steps show without scrolling.
  • No repeats. The project name and the two parties already sit above the tabs, so the card drops the address line and the parties and shows a status line instead (“Active · day 6 of 14”).
  • Four live facts. Contract total, then Paid (homeowner) or To collect (contractor), start date and expected finish. Dates come from the agreement; before it is signed those show a dash.
  • Thin progress line along the card edge, matching the project progress.
  • Quick buttons. Message, Photos, then Schedule for the homeowner or Bill for the contractor.
  • Colour kept. Same orange gradient, no big circle. The kitchen picture stays small; if you add a project photo it shows here.
  • Not built yet. This is a mockup; figures are examples.
